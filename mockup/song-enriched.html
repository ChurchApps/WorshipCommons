Art direction · Engraved plate

Colored by key, energized by tempo

Engraved plate, with the music itself picking the look: the song’s default key chooses the colorway (twelve keys across a violet-to-gold arc) and the BPM drives how energetic the linework is. Motif still comes from the themes — rivers get water lines, grace gets arcs, hope gets rays.

Decision · AI artwork

Code-drawn vs. AI-painted, side by side

Left: the engraved plate used everywhere on this page. Right: an artwork Claude painted for this mockup from the song itself — the river of life, bright as crystal, at golden hour. Production would batch-paint one per song (≈ $0.04 each via the OpenAI key already in the API), with a human glance before shipping.

Code-drawn (engraved plate)

Deterministic SVG. Free, instant for every song, always on-brand, regenerates if the design evolves.

AI-painted

Painted by Claude for this mockup, no API spend. An image model would land in this territory — richer scenes, but style drifts between songs and each needs review.
